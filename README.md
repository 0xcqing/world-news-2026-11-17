This entry for the make.fun news-image-20261117 bounty delivers `entry.png`, a 1024×1024 image summarizing world news for Tuesday, 17 November 2026. The program copies the image from the repository into the chosen output directory without changing a byte, then re-reads the result and checks its eight-byte PNG signature so a missing or corrupt output fails loudly.

## Run

```sh
MAKEFUN_OUTPUT_DIR=out node main.ts
```
